Overview

The Micro-Loan-Pool smart contract is a Clarity-based decentralized lending system built on the Stacks blockchain.
It enables the creation of community-driven loan pools, where lenders contribute funds and borrowers request micro-loans transparently.
The contract fosters financial inclusion by allowing access to capital without reliance on traditional intermediaries.

This project is prepared for submission to Code for STX
.

 Features

Pool Creation – Admins or users can create loan pools with configurable parameters.

Borrower Requests – Borrowers submit loan requests linked to specific pools.

Lender Contributions – Lenders fund pools by contributing STX.

On-Chain Tracking – Transparent pool balances and loan allocation records.

Event Logging – All pool activities (creation, contributions, requests) are logged for auditing.

Future Enhancements

Dynamic interest rate mechanisms based on pool utilization.

Integration with loan approval and disbursement workflow.

NFT-based loan agreements for borrowers.

DAO governance for validator and pool management.

Automated repayment and redistribution of funds.
